The VPM design system lives in the sibling `vpm-widgets` repo, alongside `tokens.css`, which is
canonical for both repos. This file is a pointer so the skill loads in `vpm-pages` sessions too.

**Before any VPM design work, read `../vpm-widgets/.claude/skills/vpm-design/SKILL.md`** (a
`vpm-widgets` checkout next to this repo) and follow it. Paths in that file are relative to the
`vpm-widgets` checkout, not this one.

If there's no `vpm-widgets` checkout next to this repo, say so and ask where the clone is, or
whether to clone https://github.com/mhdesigns98/vpm-widgets there. Don't answer from memory. VPM
tokens change (the display face has moved twice), and remembered values are how drift starts.
